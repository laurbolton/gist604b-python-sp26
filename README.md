## Project Description
This project demonstrates Python-based geospatial data analysis using Pandas, GeoPandas, and Rasterio. It builds functions by validating code with automated tests, and integrating tabular, vector, and raster data into reproducible GIS workflows.

## Tools and Technologies
- Python (3.11)
- Pandas
- GeoPandas
- Rasterio
- Jupyter Notebooks
- GitHub Codespaces

## What I Did
- Built reusable Python functions with input validation and error handling for data processing
- Imported and filtered tabular datasets using Pandas to calculate summary statistics
- Implemented GeoPandas workflows for vector data, including coordinate system transformations, geometry operations, and spatial joins
- Completed a raster workflow using Rasterio, including NDVI calculation, masking by polygons, and time series visualization
- Validated functionality using pytest to ensure code reliability

## How to View/Run
- Ensure required libraries are installed (Pandas, GeoPandas, Rasterio, etc )
- Open Jupyter Notebooks in the **notebooks** folder to follow step-by-step workflows
- Run Python scripts in the **src** folder for reusable function implementations
- Run pytest from the terminal to validate functions

## Repository Structure
-  README.md - project overview and documentation
- .devcontainer - development configuration file
- data/ - data files used in notebooks
 - notebooks/ - Jupyter notebooks with guided workflows
- src/ - Python scripts containing reusable functions
- tests/ - tests for validating functionality
